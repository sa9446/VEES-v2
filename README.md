# VEES - Energy, Evolved

The official landing page for **VEES** — a fast-acting, pocket-sized ₹10 caffeine jelly chew delivering 60mg of fast-acting caffeine via oral sublingual absorption.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sa9446/VEES.git
cd VEES

# Install dependencies
npm install
# or
yarn install
```

### Development

```bash
# Start the development server
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build for Production

```bash
# Build the project
npm run build

# Start the production server
npm run start
```

## 🎨 Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript
- **Deployment**: Vercel

## 📱 Features

✨ **Hero Section** - Compelling brand introduction with animated product badge

🧮 **Savings Calculator** - Interactive slider showing annual savings and benefits

📊 **Comparison Matrix** - Detailed feature comparison with competitors

🎯 **Use Cases** - Showcasing real-world applications (gym, coding, commute)

📧 **Waitlist Form** - Email capture with validation and feedback

🎭 **Smooth Animations** - Framer Motion animations throughout

🌙 **Dark Theme** - Modern glassmorphic UI with lime & cyan accents

📱 **Fully Responsive** - Mobile-first design approach
